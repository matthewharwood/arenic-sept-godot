# Title fonts

**PP Migra Extrabold** (`PPMigra-Extrabold.ttf`) is the current title wordmark font. This user-supplied commercial font was copied from `~/Library/Fonts` and imported natively by Godot without conversion. It is included in the project and is separate from the OFL fonts below.

Buttons and utility text use the `SystemFont` in `scenes/title/paper_theme.tres`, which requests Arial or Helvetica and permits Godot's fallback. No Arial or Helvetica font file was copied into the project.

The following fonts remain from the earlier title design and are unused by the current scene:

- **Rajdhani Bold** — [source](https://github.com/google/fonts/tree/main/ofl/rajdhani), license: `rajdhani-OFL.txt`.
- **Barlow Regular** — [source](https://github.com/google/fonts/tree/main/ofl/barlow), license: `barlow-OFL.txt`.

Rajdhani and Barlow are distributed under the SIL Open Font License 1.1. Their original font files and license notices are included here. Downloaded from the Google Fonts repository on September 9, 2026.
